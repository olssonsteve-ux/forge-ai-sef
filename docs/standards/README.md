# Forge Standards

Forge standards define durable engineering rules for Forge-governed work.

## Standards

- `ai-implementation-protocol.md` - mandatory protocol for AI agents implementing Engineering Briefs.
- `capability-slice-standard.md` - required structure, lifecycle, and governance rules for Capability Slices.
- `code-quality-standard.md` - code quality expectations and tooling baseline.
- `lifecycle-standard.md` - common, artifact-specific, and release lifecycle states; withdrawal, archival, reopening, and transition-evidence rules.
- `testing-standard.md` - testing expectations and verification baseline.

## Rules

- Standards should be explicit, reviewable, and traceable to Forge governance.
- Durable standard changes should update project memory.
- Architectural or governance-defining standards should have ADR support when they introduce a new permanent rule.
