# Project Boundaries

Forge is responsible for the engineering framework around software projects.

## In Scope

- project bootstrap structure
- project memory
- architecture documentation
- decision records
- engineering standards
- template management
- AI workflow guidance
- test strategy guidance
- Git workflow guidance
- release management guidance
- future automation around the above

## Out of Scope

- building end-user applications directly
- replacing product discovery
- replacing code review
- replacing human architectural accountability
- enforcing one technology stack for every future project
- requiring a hosted backend
- requiring one AI provider

## Boundary Principle

Forge should create structure and leverage. It should not create false certainty.

When Forge automates something, the underlying rule or contract should be documented first.
