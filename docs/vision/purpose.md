# Purpose

Forge exists to make AI-assisted software engineering repeatable, auditable, and durable.

Modern AI coding tools can produce code quickly, but speed without persistent context creates fragile projects. Forge addresses the layer around code: memory, standards, architecture, workflow, testing expectations, Git discipline, release discipline, and handoff quality.

Forge should become the foundation a team can place underneath a new project before the first feature is built.

## Primary Outcomes

- Projects start with clear intent.
- Architecture decisions are preserved.
- AI agents receive reliable context.
- Standards are visible and enforceable.
- Releases are planned rather than improvised.
- Future contributors understand why the project is shaped the way it is.

## Non-Goals

- Forge is not a general-purpose application framework.
- Forge is not a replacement for engineering judgment.
- Forge is not a code generator first.
- Forge is not tied to one product type, language, cloud provider, or AI vendor.
