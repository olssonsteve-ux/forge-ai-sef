# Project Brain

## Core Identity

Forge is an AI-Native Software Engineering Platform governed by CONSTITUTION.md.
It makes intent, authority, implementation and evidence inspectable across agents and sessions.

## Guiding Beliefs

Architecture and specifications precede implementation. Tests must challenge observable behavior.
Independent review may contradict green tests. Implementation, acceptance, human closure and
publication are different decisions.

## Product Shape

A deterministic local kernel surrounds a qualified coding runtime. Stable tasks isolate changes,
run explicit project checks, obtain fresh review and apply only against the captured baseline.
Project memory preserves reasons; task events preserve execution evidence.

## Important Boundaries

No automatic provider fallback, unbounded correction loop, invented approval or silent recovery.
Verification commands are trusted operator policy. Agent tool permissions remain restricted.
Historical experimental defects are not repaired by changing package scope. No release without
release evidence and authority. The owner authorized public testing publication on 2026-10-11;
this does not establish stable runtime acceptance.

## Current Decisions

ADR 0018 establishes proportionate records: one assurance owner and persistent in-scope authority.
ADR 0019 establishes the stable isolated task kernel, target CLI and explicit FAL quarantine.
[Forge Concept v1.0](docs/Forge-Concept-v1.0.md) freezes purpose and scope. The owner selected MIT
and authorized GitHub public testing as a prerelease; external AI costs remain separate.
The [assurance record](docs/engineering/Forge-1.0-assurance.md) owns detailed acceptance evidence.
[PROJECT_STATE](PROJECT_STATE.md) alone owns current progress and next gate.

## Open Questions

Additional platforms/runtimes need independent qualification before support claims expand.
Future providers must satisfy the same authority, interruption and review contracts.
Human acceptance of Audio Recorder's native UI is a separate product gate, not Forge runtime proof.
