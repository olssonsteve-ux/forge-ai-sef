# Standards

This directory will contain Forge engineering standards.

Standards are not implementation features. They are human-readable expectations that later automation may inspect.

## Planned Standards

Planned standards include:

- architecture standards
- documentation standards
- testing standards
- Git workflow standards
- AI collaboration standards
- release management standards

See `categories.md` for standard categories and acceptance criteria.

## Acceptance Criteria

A Forge standard should define:

- the behavior or practice expected
- why the standard exists
- where it applies
- what is explicitly out of scope
- how exceptions are documented
- whether it is advisory or required

## Evolution Rule

Standards should be human-readable before they become machine-checkable.

No validation automation should be added until the relevant standard is accepted and stable enough to test.
